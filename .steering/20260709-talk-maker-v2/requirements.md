# 要求内容（talk-maker v2）

## 概要

トーク画面メーカー初版へのユーザーフィードバックに基づく機能追加・バグ修正。

## 実装対象

### 1. PNG書き出しズレの修正（バグ・最優先）
- 書き出した画像が右にずれ、左に余白・右が見切れる問題を修正する
- 原因: html-to-image が中央寄せ（margin: auto）の計算済みマージンをクローンに引き継ぐため

### 2. 画像インポート（背景・アイコン）
- トークアイコン・メンバーアイコンに画像をアップロードできる（絵文字も引き続き使える）
- アイコンはドラッグ＋ズームで切り抜きできる（円形プレビュー）
- 背景に画像を設定できる（テーマ背景も引き続き使える。cover表示）

### 3. フォント変更
- ゴシック/丸ゴシック/明朝/等幅 の4種から選べる（システムフォントのみ）

### 4. JSONインポート/エクスポート
- JSON形式でトークを一括インポートできる（テキスト貼り付け・ファイル選択）
- 置き換え/追記を選べる。バリデーションエラーは日本語で表示
- 対でJSONエクスポートも提供（画像メッセージは対象外）

### 5. 選択モード
- 吹き出しを複数選択し、一括削除・時刻一括変更・送信者一括切替ができる
- 選択したメッセージだけをPNG保存できる

### 6. グループチャット
- 相手側メンバーを複数登録できる（名前＋絵文字 or 画像アイコン）
- グループ時は吹き出しの上にメンバー名を表示、メッセージごとに送信メンバーを選べる

### 7. 画像メッセージ
- 画像をアップロードしてトーク内に送信できる（LINEの写真送信風の表示）

## 受け入れ条件

- [ ] 書き出したPNGにズレ・見切れがない
- [ ] アイコン/背景画像がプレビューとPNG出力の両方に反映される
- [ ] フォント切替がプレビューとPNG出力の両方に反映される
- [ ] 不正なJSONで日本語エラーが表示され、正しいJSONでインポートできる
- [ ] 選択モードで一括操作と部分スクショができる
- [ ] メンバー2人以上でグループ表示（名前ラベル）になる
- [ ] 既存の保存データ（v1形式）を読み込んでも壊れない
- [ ] `yarn test` / `yarn lint` / `yarn build` が全て成功する

## スコープ外

- スタンプ機能・JSONへの画像メッセージ含有・グループの既読人数表示（「既読 3」）
- 外部フォント（Google Fonts等）の利用
