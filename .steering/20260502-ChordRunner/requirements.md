# 要求内容

## 概要

ギター初心者向けコードチェンジ練習Webアプリ「ChordRunner」。ユーザーが組んだコード進行をBPMに合わせて自動再生し、現在コードと次コードを指板上にゴースト表示で重ねて見せることで、リズムに乗ったコードチェンジを反復練習できる。

## 背景

ギター学習の最初の壁である「コードチェンジ（次コードへの指の移動）」は、単に各コードを覚えるだけでなく、リズムを保ちながら素早く指を動かす反復練習が必要。ビジュアルで次コードの運指を先行表示（ゴーストフレット）することで、頭の切り替えを補助する。

## 実装対象の機能

### 1. コード進行ビルダー（ChordBuilder）
- 画面に表示されたコードボタンをクリックしてタイムラインにコードを追加できる
- 追加したコードをタイムラインから削除できる
- 1〜16コードの任意の長さで進行を組める

### 2. ゴーストフレット表示（Fretboard）
- 指板SVGに現在コードの運指を黒ドットで表示する
- 同じ指板上に次コードの運指を薄い色（opacity 0.3）でゴースト表示する
- 現在と次が同弦・同フレットで重なる場合は枠線のみのドーナツ形状で表示する

### 3. BPM・拍数設定と音声再生（BpmControl / PlaybackControls / useAudioPlayer）
- スライダーまたは数値入力でBPMを40〜200の範囲で設定できる
- 1コードあたりの拍数を2拍または4拍で切り替えられる
- 再生ボタンでTone.jsのTransportが動き、BPMに合わせてメトロノーム音とコード音が再生される
- コードインデックスがbeatsPerChordごとに自動で進む

### 4. 収録コードデータ（chordData.ts）
- C, G, D, A, E, Am, Dm, Em, F, Bm の10コードを定義する
- 各コードは弦ごとのフレット番号と音声再生用ルートノートを持つ

## 受け入れ条件

### コード進行ビルダー
- [ ] 10種類のコードボタンが表示される
- [ ] ボタンをクリックするとタイムラインにコードが追加される（最大16）
- [ ] タイムライン上のコードを削除できる
- [ ] 1コード以上設定されていない場合、再生ボタンが無効化される

### ゴーストフレット表示
- [ ] 6弦・指板が正しいスケールでSVG描画される
- [ ] 現在コードのポジションが黒ドットで表示される
- [ ] 次コードのポジションがopacity 0.3の透過ドットで表示される
- [ ] 重複ポジションは枠線のみ（fill: none）のドットで表示される

### 音声再生
- [ ] 再生中、設定BPMでメトロノーム音が鳴る
- [ ] コード切り替えタイミングにコード音（ルートノート）が鳴る
- [ ] 停止ボタンで再生とTransportが停止する
- [ ] 停止後に再生ボタンを押すとコード0番目から再スタートする

### ページ統合
- [ ] `/gallery/tool/chord-runner` でアクセスできる
- [ ] `/gallery/tool` のtoolsリストにChordRunnerが追加される

## 成功指標

- BPM80・4拍のC→G→Am→Fのループが音とともに正しく動作する
- コードチェンジ時に指板の表示が瞬時に切り替わる（ちらつきなし）

## スコープ外

以下はこのフェーズでは実装しません:

- ドラッグ＆ドロップでのタイムライン並び替え
- セブンス系・sus4などの拡張コード
- ギターサンプラー音源（メトロノーム音のみ + Tone.js Synth でコード音を代替）
- ユーザー設定の永続化（localStorage保存）
