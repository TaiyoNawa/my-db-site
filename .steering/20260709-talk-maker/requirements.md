# 要求内容

## 概要

チャット風のトーク画面を自由に作成し、PNG画像として保存できるジェネレーター「トーク画面メーカー（talk-maker）」を便利ツールに追加する。

## 背景

- `docs/ideas/monetization-strategy.md` Phase 1 の集客コンテンツ施策。「LINE 画像 作成」系は検索需要が大きく、SNSでシェアされやすい
- 既存ツール（es-counter）と同じ features/ 構造で追加でき、広告ゾーン（/gallery/tool/*）の主力コンテンツになる
- ※ LINE は商標のため、サイト上の名称は「トーク画面メーカー」とし、LINE のロゴ・商標は使用しない

## 実装対象の機能

### 1. メッセージ作成（WYSIWYG編集）
- チャットアプリ風の入力バーからメッセージを追加できる（Enter送信対応）
- 送信者を「自分（右・緑バブル）/ 相手（左・白バブル）」で切り替えられる
- プレビュー内の吹き出しをタップすると、その場で編集・削除・送信者切替・時刻変更ができる（一覧とプレビューの二重管理をしない）

### 2. トーク画面プレビュー
- スマホ実機風フレーム内にリアルタイムでトーク画面が描画される
- 相手の名前・アイコン（絵文字）を設定でき、ヘッダーに反映される
- 背景テーマ（ブルーグレー/ダーク/グリーン/ピンク等）を切り替えられる
- 時刻表示・既読表示のON/OFFを切り替えられる
- 同じ送信者の連続メッセージではアイコンを省略する（本物らしい挙動）

### 3. PNG画像エクスポート
- プレビューをそのままPNG画像としてダウンロードできる（高解像度 2x）
- エクスポート失敗時は日本語のエラーメッセージをトーストで表示する

### 4. 入力内容の保持
- sessionStorage に自動保存し、リロードしても作業が消えない（es-counter と同パターン）

## 受け入れ条件

### メッセージ作成
- [ ] 入力バーからメッセージを追加できる（ボタン・Enterの両方）
- [ ] 送信者トグルで自分/相手を切り替えて追加できる
- [ ] 吹き出しタップで編集ポップオーバーが開き、本文・時刻・送信者の変更と削除ができる

### プレビュー
- [ ] 相手の名前・アイコンがヘッダーに反映される
- [ ] 背景テーマの切り替えが即座に反映される
- [ ] 時刻・既読の表示切替が機能する
- [ ] モバイル幅でもレイアウトが崩れない

### PNG出力
- [ ] ダウンロードしたPNGがプレビューと同じ見た目である
- [ ] メッセージ0件のときはエクスポートボタンが無効になる

### 共通
- [ ] `yarn test` / `yarn lint` / `yarn build` が全て成功する
- [ ] `/gallery/tool` の一覧にカードが表示され、遷移できる

## 成功指標

- 検索キーワード「トーク画面 作成」「チャット 画像 ジェネレーター」等での流入獲得（Search Console導入後に計測）
- 操作説明なしで初見ユーザーが画像作成まで到達できるUI

## スコープ外

以下はこのフェーズでは実装しません:

- 画像アイコンのアップロード（絵文字アイコンのみ。将来拡張）
- グループトーク（3人以上・名前表示付きバブル）
- スタンプ・画像メッセージ
- iPhone風ステータスバー（時刻・電池アイコン）の再現
- 使い方解説記事（Notion側で別途作成）
